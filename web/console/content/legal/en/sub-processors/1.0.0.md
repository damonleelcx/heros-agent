This document names every third party that receives anything from this Service, what each one receives,
which surfaces it runs on, and where it processes. It is **material**: publishing a new version of it
resets every non-essential consent choice to unanswered and asks again, because a grant is given against
a statement of who receives data, and this is that statement.

## 0. The fact that shapes the rest

**There is no vendor-operated hosted deployment today.** Every deployment of this Service in existence is
run by a customer or by an operator on their behalf, including an air-gapped package with no outbound
network access at all.

The three processors below are configured **only for the vendor's own hosted deployment** — the public
website and, when it exists, the vendor-run console. On a customer's Compose or Kubernetes install, and
in the air-gapped package, **all three are absent**: the package carries no measurement id, no project
id and no reporting endpoint, and that absence is checked when the package is built rather than
described afterwards.

## 1. The processors

| Processor | What it receives | Surfaces | Gated on | Processes in |
|---|---|---|---|---|
| **Google LLC** (Google Analytics 4) | Page views and named funnel steps from the public website. IP anonymisation on, no client identifier stored, no advertising or cross-site signals, no remarketing audience, no conversion pixel | The public website only. **Never** a signed-in page and never the operator console | *Usage analytics* — off until you turn it on | United States |
| **Microsoft Corporation** (Clarity) | A recording of how a page of the public website was scrolled and clicked, with **all** text and form input masked | The public website only. **Refused** on signed-in pages and on the operator console, structurally | *Session recording* — off until you turn it on | United States |
| **Functional Software, Inc.** (Sentry) | The type, the classification code, the stack and the build of a failure. **No** message text, **no** page address, **no** request or response content, and no breadcrumb collection of any kind | The public website, signed-in pages, and the operator console | *Error diagnostics* — off until you turn it on, except on the operator console, where it is covered by the internal acceptable-use notice rather than by a banner | United States |

## 2. What none of them receives

Not as a redaction, and not as a setting we could change — as a field that does not exist in what is
sent:

Prompt, completion, source or diff text · run, variant, node or workflow identifiers · tenant
identifiers or tenant names · principal identifiers, names or email addresses · request or response
bodies · request or response headers · query strings · page addresses · console output · the text of
anything you clicked · credentials of any kind · hostnames, server names or IP addresses beyond the
anonymisation described above.

The complete, generated list of what an error report *can* contain is published at
`docs/decisions/p24-error-event-allowlist.md`, rendered from the code that builds the report so the two
cannot drift.

## 3. Your choices

- Every optional category is **off until you turn it on**, and nothing is loaded before you do.
- **Declining changes nothing else.** Every page, every control and every route works identically.
- A refusal is remembered. You are not asked again until this document changes materially.
- You can change your mind at any time from **Privacy choices**, at the bottom of any page. It takes
  effect on your next navigation and needs no sign-out.

## 4. If you run this Service yourself

Nothing in section 1 applies to your deployment. Your install carries no measurement id, no project id
and no reporting endpoint, and there is no configuration that would make it acquire one by accident —
the package build fails if an artefact references an external origin at all.

**You cannot currently point error reporting at a collector of your own.** That would be a self-hosted
ingest endpoint, and it has not been built. It is a real gap and it is written here rather than left to
be discovered.
